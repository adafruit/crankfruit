# retained original startup lockup

`approved-startup-lockup.png` is the approved 400 x 240 one-bit original
Crankfruit startup artwork. It was previously generated with the built-in image
tool and compiled using Atkinson error diffusion. No specific backend model
identity was exposed. This file preserves that approved raster as a portable
build input; this UI update does not generate a replacement.

The UI compiler uses only the CRANKFRUIT wordmark rectangle at x8..391,
y171..221, scaled to258x34 logical pixels with nearest-neighbor sampling.
Its animated tiny apple is separate original code-native artwork.
